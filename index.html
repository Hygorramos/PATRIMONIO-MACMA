Configuração necessária

Este sistema precisa do seu projeto Firebase para funcionar.

Como ativar

Abra o arquivo index.html e cole as chaves do seu Firebase no bloco firebaseConfig (lá no início do <script>). Depois publique no GitHub Pages.

  1. Crie um projeto em console.firebase.google.com
  2. Ative Authentication → E-mail/senha
  3. Crie o Firestore Database
  4. Copie a config do app web e cole no arquivo

O passo a passo completo está no arquivo GUIA-INSTALACAO.md que veio junto.
